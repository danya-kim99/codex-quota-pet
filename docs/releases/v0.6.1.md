Quota-history continuity and chart-clarity fixes for Apple silicon Macs running
macOS 14 or newer.

## Fixed in this release

- Kept the most recent completed quota trend visible as `Earlier` after an app
  relaunch, reconnect, or wake while the new observation segment is still being
  collected. The summary switches back to the current segment as soon as two
  comparable observations exist.
- Prevented an older persisted endpoint from being presented as the current
  quota while live quota data is unavailable during startup or reconnect.
- Kept the chart's 24-hour range current after duplicate accepted reads without
  storing unnecessary snapshots.
- Added clearer fixed `0–100%` and 24-hour axes, an outlined current point,
  directly labelled gap and reset boundaries, and a reset marker positioned
  between observations instead of on a measured value.
- Improved chart-label readability and spacing in both Smooth and Pixel
  tooltips, including a clear separation between `0%` and `24 h ago`.
- Kept the same truthful history summary in the tooltip, pet, menu-bar
  VoiceOver output, and missing-current-value state.

## Privacy and compatibility

- History remains a local record of observed integer percentages, not exact
  token usage or complete account activity.
- The storage format, 30-day retention, 2,000-snapshot cap, saved preferences,
  and network behavior are unchanged. No migration or new dependency is needed.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.6.1-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved size, tooltip style, visibility, quota dynamics, and
   local history are preserved.

A locally installed and authenticated Codex CLI is required.
