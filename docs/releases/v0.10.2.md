Quota-consumption reactions have been removed, substantially reducing the application and update download size.

The black hole still changes shape with remaining quota and keeps its normal
rotation, Standard/Turbo behavior, Reduce Motion support, hover/click feedback
and object absorption. Quota history, settings and the built-in updater remain
available.

Version **0.10.2 (build 25)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** in the native menu bar.
Compatibility remains Apple silicon, macOS 14 or newer, with ad-hoc signing.
