Local quota history, clearer reset countdowns, and refined Pixel tooltips for
Apple silicon Macs running macOS 14 or newer.

## New in this release

- Added an optional local quota-dynamics view to both Smooth and Pixel
  tooltips. Medium and large pets show a compact 24-hour chart; the small pet
  shows a text summary.
- Added `Show Quota Dynamics` to the menu. It is on by default and controls
  presentation only, so local history can keep collecting while the chart is
  hidden.
- Added `Clear Local History…` with confirmation and localized English and
  Russian status messages.
- Made the reset countdown more useful near the boundary: it shows days when
  at least a day remains, hours below one day, and minutes plus seconds below
  one hour. The per-second update runs only while the tooltip is visible.

## Privacy and resilience

- History contains only locally observed integer percentage snapshots and
  timestamps. It does not store exact token counts or full account activity,
  and it is never uploaded or synchronized by the app.
- Local history is retained for up to 30 days with a 2,000-snapshot cap.
- Gaps, resets, corrections, reconnects, stale or missing data, wake, corrupt
  files, and failed writes are handled without inventing continuity.

## Refined in this release

- Kept the Pixel tooltip and context-menu hard shadows inside their panels
  across S, M, and L sizes.
- Preserved the shared quota content and behavior across Standard and Turbo,
  Smooth and Pixel, English and Russian, VoiceOver, and Reduce Motion.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.6.0-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved size, tooltip style, visibility, and quota-dynamics
   settings are preserved.

A locally installed and authenticated Codex CLI is required.
