## Reset information that stays clear

- Personal manual-reset credits always stay in the card header, independently
  of public announcements. Zero credits and unavailable account data are distinct.
- Optional Codex Resets announcements now have their own labelled section, with
  separate loading, empty and unavailable states. A scheduled event and a recent
  reported reset can appear together without duplicate events.
- Announcements refresh while the card is visible, subject to the existing
  minimum interval and server cache/retry guidance. Public reports never confirm
  that your own quota or credits have changed.
- Long unavailable-time messages and dates fit in Smooth cards; Pixel's
  unavailable-quota hatching stays inside its progress bar.

## Compatibility and regression coverage

- Finds the Codex CLI nested inside newer ChatGPT/Codex application bundles while
  preserving the existing executable-validation and fallback order.
- Adds 768 deterministic card snapshots spanning 32 scenarios, English/Russian,
  Smooth/Pixel, three sizes and history on/off.

Version **0.13.0 (build 30)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** in the native menu bar.

Compatibility remains Apple silicon and macOS 14 or newer. This is an ad-hoc
signed preview, not a Developer ID-notarized application. Reset announcements
remain opt-in; no network/VPN settings, reset-consume operation or account-data
sharing are added.
