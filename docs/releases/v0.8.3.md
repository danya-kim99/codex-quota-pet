A focused connection-lifecycle reliability update for Apple silicon Macs running
macOS 14 or newer.

## Fixed in this release

- Quota, speed-mode, and failure callbacks already queued by an older Codex App
  Server connection are now discarded after the app stops that connection or
  starts a replacement.
- Manual retry can no longer be overwritten by stale quota data or trigger an
  extra reconnect from an older connection.

## Privacy and compatibility

- This update introduces no network request, process, dependency, backend,
  analytics, permission, preference, or stored-data change.
- Existing Smooth/Pixel styles, S/M/L sizes, Standard/Turbo, Reduce Motion,
  authored quota reactions, Object Mix controls, position controls, launch at
  login, and saved local history are preserved.
- The preview remains arm64-only and requires macOS 14 or newer plus a locally
  installed and authenticated Codex CLI.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.8.3-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings and local quota history are retained.

## Verification

- Focused lifecycle tests cover queued callbacks before stop and manual retry,
  plus the existing manual and automatic reconnect behavior.
- The release workflow runs the complete macOS test suite, validates the arm64
  bundle metadata and ad-hoc signature, checks the ZIP checksum, and verifies
  the published asset digest.
