Selectable Smooth and Pixel quota tooltips for Apple silicon Macs running
macOS 14 or newer.

## New in this release

- Added a persisted tooltip-style picker to the menu bar and the pet's pixel
  context menu. Choose Smooth / Pixel in English or Обычный / Стилизованный in
  Russian.
- Added a code-native Pixel quota tooltip with dedicated L/M and compact S
  layouts, Standard/Turbo details, quota thresholds, reset information, and
  pointers for every screen placement.
- Switching styles updates an open tooltip immediately while preserving its
  screen side when possible, keeping the pet stationary, and avoiding extra
  quota traffic.
- Kept the original Smooth presentation visually unchanged and shared semantic
  formatting, missing/stale handling, localization, and VoiceOver summaries
  between both styles.
## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.5.0-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings are preserved; existing installations start
   with the Smooth tooltip until another style is selected.

A locally installed and authenticated Codex CLI is required.
