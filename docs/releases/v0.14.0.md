## Companions and response-ready notices

- Choose a companion from the shared Smooth/Pixel catalogue. It includes ten
  named characters, including Паша, and 24 space objects and animals.
- The magnifier uses detailed original artwork with three zoom levels; the grid
  and pet use the existing pixel sprites. Selection is saved locally.
- The companion can orbit during work and disappear afterwards. Reduce Motion
  keeps it still. Automatic activity remains an experimental, explicitly enabled
  Codex hooks integration: the app does not install or trust hooks, and a
  normal launch without the configured activity token does not enable the orbit.

### Response-ready notices beside the pet

- Optional Smooth and Pixel notices show when a local Codex response is ready,
  with the chat name when available. Failed, interrupted and child turns are
  excluded. A ready response does not necessarily mean the entire task is done.
- Close a notice immediately with its visible × button. The eight-second timer
  pauses while the pointer or keyboard/accessibility focus is on the card and
  resumes with the remaining time. Grouped completions do not restart it.
- Hovering the pet, dragging, menus and visibility rules retain priority. Old
  or dismissed events are not replayed. Both menus share the default-off setting,
  with English and Russian labels.
- Native menu suppression now follows actual menu opening and closing. An
  interrupted status without a completion timestamp is retried briefly to handle
  a final response arriving before its saved status has settled.

### Enable and move safely

Place the app at its permanent location, normally `/Applications`, before
enabling **Notify When Response Is Ready / Сообщать о готовом ответе** in Behavior.
The integration preserves an existing Codex notification command. Existing chats
may require restarting Codex after setup.

Before moving or deleting the app, or downgrading to a version without this
integration, turn the setting off, confirm that no configuration error is shown,
then restart Codex. This restores the previous notification command. An ordinary
update at the same application path does not require moving the integration.

Version **0.14.0 (build 33)** includes the features above. Release build and
package verification are recorded with the release artifacts. Companion appearance/disappearance through the configured
local Codex hooks was confirmed during prototype testing. Completion-card
delivery after the latest fix, first-click behavior, fourth-row scrolling,
keyboard focus and VoiceOver still require interactive acceptance.

The current local hooks reference a separately retained helper executable.
Keep that helper at its configured path until the integration is explicitly
migrated; merely unpacking an update does not update those references.

Compatibility remains Apple silicon and macOS 14 or newer. The distribution
format remains an ad-hoc signed preview, not a Developer ID-notarized application.
