Pixel-tooltip appearance fix for Apple silicon Macs running macOS 14 or newer.

## Fixed in this release

- Removed the brief shadow jump when a Pixel tooltip appears. The Pixel panel
  now bypasses the default macOS window scale/fade animation, so its stepped
  frame, pointer, and hard shadow render at their final geometry immediately.
- Kept the existing Smooth tooltip window behavior unchanged.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.5.1-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved size, tooltip style, and visibility settings are
   preserved.

A locally installed and authenticated Codex CLI is required.

## Verification

- 51 macOS unit tests passed locally, including the Smooth/Pixel window-animation
