Custom object mixes and authored quota reactions for Apple silicon Macs running
macOS 14 or newer.

## Added in this release

- Added persistent relative weights from `0` to `3` for space objects, animals,
  and characters. A zero weight excludes a category, the default remains
  `2 : 2 : 1`, and the last active category cannot be disabled.
- Added the approved mouse-first 3 × 4 Object Mix matrix to the Pixel context
  menu. Changes apply to the next accepted absorption immediately and the menu
  stays open for successive edits; the native menu bar exposes the same values.
- Restored quota-consumption reactions with authored Small, Medium, Large, and
  Last Light frame sequences. They reuse the existing accepted quota transition,
  add no quota reads, and use a bounded alternative when Reduce Motion is active.

## Privacy and compatibility

- Object weights are stored only in the existing local preferences. Reactions
  and their cadence remain session-local and are never persisted or replayed.
- This release adds no network request, process, dependency, backend, analytics,
  permission, cloud storage, or quota control.
- Existing Smooth/Pixel styles, S/M/L sizes, Standard/Turbo, position controls,
  launch at login, saved local history, and the 33-object catalog are preserved.
- The preview remains arm64-only and requires macOS 14 or newer plus a locally
  installed and authenticated Codex CLI.
- The app bundle is about 274 MiB because the complete authored reaction matrix
  is bundled locally; no reaction asset is downloaded at runtime.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.8.0-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings and local quota history are retained.
