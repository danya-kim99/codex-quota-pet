Pixel-tooltip ring fix for Apple silicon Macs running macOS 14 or newer.

## Fixed in this release

- Kept the white Turbo chevrons fully inside the circular quota arc in the
  compact S-size Pixel tooltip.
- Aligned the arc, chevrons, and lightning marker to one shared ring geometry
  without changing the Smooth tooltip style.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.5.2-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved size, tooltip style, and visibility settings are
   preserved.

A locally installed and authenticated Codex CLI is required.
