A smaller context menu and an optional Codex-only visibility mode for Apple
silicon Macs running macOS 14 or newer.

## New in this release

- **Only When Codex Is Active** hides the pet when another application becomes
  active and brings it back when you return to Codex. The setting is off by
  default, is saved locally, and is available from both the menu bar and the
  pet's **Behavior** submenu. Manual hiding and fullscreen hiding retain their
  priority; the menu bar remains available while the pet is hidden.
- The pet's right-click menu now opens with five items: **Appearance**, **Object
  Mix**, **Behavior**, **Hide Pet**, and **Quit**. Retry appears only when needed.
- **Appearance** groups size, tooltip style, and quota dynamics. **Behavior**
  groups position, pointer input, visibility, and launch-at-login settings.
  Options use a single submenu level, with mouse and keyboard navigation.
- English and Russian labels, checked states, help text, and accessible section
  headings are included. Opening a taller submenu keeps the main menu in place.

## Fixed

- A delayed view lifecycle callback can no longer mark a hidden pet as visible
  and allow a quota reaction to start while it is hidden.

## Compatibility and privacy

- Saved settings, local quota history, Object Mix weights, Smooth/Pixel styles,
  S/M/L sizes, Standard/Turbo, and Reduce Motion behavior are preserved.
- The update adds one local preference and requires no new permission, service,
  dependency, analytics, or network endpoint.
- This remains an arm64-only preview for macOS 14 or newer and requires a
  locally installed and authenticated Codex CLI. It uses the existing ad-hoc
  signing channel; Developer ID signing and notarization are not included.

## Install or update

1. Download `Black-Hole-Codex-Quota-Indicator-v0.9.0-macos-arm64.zip` and its
   matching `.sha256` file.
2. Verify the checksum and unzip the archive.
3. Quit the running app and replace the copy in `/Applications`.
4. Open the app. Your saved settings and quota history are retained.

## Verification

The release workflow runs the complete macOS test suite, builds the arm64
Release app, checks bundle metadata and its ad-hoc signature, and verifies the
published ZIP digest. Focused checks cover foreground visibility, menu
navigation, conditional actions, geometry, and bundled RU/EN strings. The menu
was also exercised live in both languages before release preparation.
