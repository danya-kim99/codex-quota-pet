Menu bar and animation fixes for Apple silicon Macs running macOS 14 or newer.

## Fixed in this release

- Replaced the menu bar icon with a crisp 20 × 20 monochrome template that follows the system appearance in both light and dark menu bars.
- Absorbable objects now remain fully inside the pet panel throughout their approach at every S, M, and L pet size, including while rotating and stretching.
- Removed stray pixels imported from a neighboring master-sheet cell in the 40% and 10% quota animations.
- Refreshed the README previews so the corrected quota sprites display immediately on GitHub.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.4.1-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing the previous copy when prompted.
4. Open the app. Saved settings are preserved.

A locally installed and authenticated Codex CLI is required.
