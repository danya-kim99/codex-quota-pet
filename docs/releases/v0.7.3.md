Clearer local quota history for Apple silicon Macs running macOS 14 or newer.

## Improved in this release

- Added an adaptive vertical chart scale so slow percentage changes remain
  legible while all displayed observations stay inside the labeled range.
- Kept the fixed 24-hour timeline and added actual upper and lower percentage
  labels, making the increased detail explicit without hover or interactive
  zoom.
- Merged consecutive history gaps into one dashed span. Real continuous quota
  segments and reset markers still split spans, while overlapping internal
  borders no longer create a dense white fence.

## Privacy and compatibility

- History remains local-only and stores the same observed integer percentages
  and continuity metadata as before.
- This refinement adds no network request, process, dependency, permission,
  preference, analytics, or cloud storage.
- Existing Smooth/Pixel styles, S/M/L sizes, Standard/Turbo, Reduce Motion,
  position controls, launch at login, and saved local history are preserved.
- The preview remains arm64-only and requires macOS 14 or newer plus a locally
  installed and authenticated Codex CLI.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.7.3-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings and local quota history are retained.
