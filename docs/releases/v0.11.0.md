Adds an optional third-party forecast for upcoming extra Codex resets.

Enable **Show Codex reset forecast / Показывать прогноз сброса Codex** in the
native menu bar. When codex-resets.com reports an active signal, the tooltip
header shows the forecast or announced reset state. Personal quota, reset time,
history and connection status remain unchanged.

The setting is off by default. When enabled, Black Hole makes an unauthenticated
HTTPS request to codex-resets.com and sends no Codex credentials or account,
quota, history, project or prompt data. Invalid, unavailable or expired external
data falls back to the ordinary tooltip title.

Version **0.11.0 (build 26)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** in the native menu bar.
Compatibility remains Apple silicon, macOS 14 or newer, with ad-hoc signing.
