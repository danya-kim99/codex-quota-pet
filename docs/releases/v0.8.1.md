One new pixel-art character for Apple silicon Macs running macOS 14 or newer.

## Added in this release

- Added the approved compact character with side-swept brown hair, a friendly
  smile, light stubble, a charcoal blazer, and a white band-collar shirt.
- Expanded the absorbable catalog to 34 models with ten characters while
  preserving the existing category defaults, saved Object Mix preferences,
  animation, and interaction behavior.

## Privacy and compatibility

- This asset-only addition introduces no network request, process, dependency,
  backend, analytics, permission, preference, or stored data.
- Existing Smooth/Pixel styles, S/M/L sizes, Standard/Turbo, Reduce Motion,
  authored quota reactions, Object Mix controls, position controls, launch at
  login, and saved local history are preserved.
- The preview remains arm64-only and requires macOS 14 or newer plus a locally
  installed and authenticated Codex CLI.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.8.1-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings and local quota history are retained.
