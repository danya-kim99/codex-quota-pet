Compact, readable quota details for the S-size pet on Apple silicon Macs running macOS 14 or newer.

## New in this release

- The S-size pet now uses a dedicated 248 × 112 pt tooltip card instead of shrinking the full layout to 60%.
- A circular indicator shows the exact remaining quota with the existing gold, orange, and purple thresholds.
- Standard mode uses a clean quota arc; Turbo adds directional chevrons and a bolt marker without introducing new motion.
- The compact card keeps the localized reset countdown, date, and time while removing the redundant day-segment strip.
- Tooltip placement remains fully on-screen at every S, M, and L pet size; the existing L and M layouts are unchanged.
- Added automated GitHub Actions testing and validated preview-release publishing.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.3.1-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing the previous copy when prompted.
4. Open the app. Saved settings are preserved.

A locally installed and authenticated Codex CLI is required.
