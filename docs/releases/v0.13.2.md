## Matching controls in both menus

- The pet's right-click Appearance menu now includes the existing Codex reset
  forecast setting, provider link and local history controls, matching the menu bar.
- Both menus use the same saved forecast setting and the same history-clear
  confirmation, with Cancel selected by default. The context menu closes before
  opening the provider link or confirmation.
- Keyboard navigation follows the visible controls and handles the conditional
  provider link. The expanded submenu fits the existing panel size.

Version **0.13.2 (build 32)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** from either menu.

Compatibility remains Apple silicon and macOS 14 or newer. Distribution remains
an ad-hoc signed preview, not a Developer ID-notarized application.
