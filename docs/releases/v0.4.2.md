Three new user-approved pixel characters for Apple silicon Macs running macOS
14 or newer.

## New in this release

- Added a character in a cream sweater, wide black trousers, and rectangular
  glasses.
- Added a character in a black T-shirt, olive cargo skirt, and crossbody bag.
- Added a bearded character in black shorts and a botanical overshirt.
- Expanded the manifest-driven absorption catalog from 28 to 31 models while
  preserving the existing category weights and interaction behavior.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.4.2-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings are preserved.

A locally installed and authenticated Codex CLI is required.
