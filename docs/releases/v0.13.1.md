## Consistent menus

- The menu-bar menu now follows the pet's right-click menu: Appearance,
  Object Mix and Behavior, followed by visibility, updates and quit actions.
- Size and tooltip style choices appear directly inside Appearance. Existing
  quota details, reset announcements, history controls and settings remain
  available.
- Check for Updates is now also available in the pet's right-click menu.
  Both menus use the same updater and disable the action while unavailable;
  keyboard navigation skips the disabled item.

Version **0.13.1 (build 31)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** from either menu.

Compatibility remains Apple silicon and macOS 14 or newer. Distribution remains
an ad-hoc signed preview, not a Developer ID-notarized application. Update policy,
saved preferences, quota collection and privacy behavior are unchanged.
