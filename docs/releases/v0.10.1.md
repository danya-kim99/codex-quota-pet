Technical patch for testing the built-in update from version 0.10.0.

## About this update

The application version is now **0.10.1 (build 24)**. Application behavior is
unchanged; this patch lets existing 0.10.0 installations exercise the signed
GitHub download, installation and relaunch flow.

## Test the update

1. In Black Hole 0.10.0, choose **Check for Updates… / Проверить обновления…**
   from the native menu bar.
2. The updater should offer version 0.10.1. Choose Install Update, then Install
   and Relaunch when the download is ready.
3. Confirm that the application returns and your settings and quota history
   remain available. A new check should report no newer version.

The release uses the same signing key and retains the previous signed feed
entry. Compatibility remains Apple silicon, macOS 14 or newer, with ad-hoc
signing and no Developer ID notarization. macOS security confirmation may
still be required.
