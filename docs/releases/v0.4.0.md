A custom pixel-art context menu for the black-hole pet on Apple silicon Macs running macOS 14 or newer.

## New in this release

- Secondary-click or Control-click the visible black hole to open a localized pixel-art context menu without triggering absorption or dragging.
- Access Retry Now when disconnected, the S/M/L size selector, fullscreen hiding, Launch at Login, Hide Pet, and Quit directly from the pet.
- Conditional items, toggle states, enabled states, and checkmarks update live while the menu is open.
- The menu opens near the pointer, chooses an available screen quadrant, and remains fully visible at every pet size.
- Normal motion uses a reversible pixel-spaghettification transition; Reduce Motion uses a short stepped fade.
- Added keyboard navigation with the arrow keys, Return, Space, and Escape, plus localized VoiceOver actions and menu state.
- Opening the menu suppresses the quota tooltip and blocks new absorptions while existing absorption animations continue behind it.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.4.0-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing the previous copy when prompted.
4. Open the app. Saved settings are preserved.

A locally installed and authenticated Codex CLI is required.
