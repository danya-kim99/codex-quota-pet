More consistent cartoon character art for Apple silicon Macs running macOS 14
or newer.

## Refined in this release

- Replaced the cargo-skirt and botanical-shirt characters with the approved
  more cartoonish pixel-art versions. Their larger rounded heads, compact
  proportions, expressive eyes, and simplified clothing details now match the
  established white-shirt, purple-shirt, and green-hoodie character family.
- Made that character style explicit in the reusable generation skill so future
  additions use the same canonical anchors and reject realistic proportions,
  dense micro-patterns, smoothing, and portrait-like rendering.
- Kept the catalog at 31 absorbable models with seven characters and preserved
  the existing `2 : 2 : 1` category weights, IDs, animation, and interaction.

## Privacy and compatibility

- This asset-only refinement adds no network request, process, dependency,
  backend, analytics, permission, preference, or stored data.
- Existing pet size, tooltip style, visibility, quota-dynamics preference,
  local history, position controls, and launch-at-login state are preserved.
- The preview remains arm64-only and requires macOS 14 or newer plus a locally
  installed and authenticated Codex CLI.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.7.2-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings and local quota history are retained.
