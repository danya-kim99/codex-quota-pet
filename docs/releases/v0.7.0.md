Quota reactions, clearer mode semantics, and safer pet placement for Apple
silicon Macs running macOS 14 or newer.

## New in this release

- Added a short pixel-light reaction when the app confidently observes quota
  consumption within the same primary window. Larger observed drops receive a
  stronger finite reaction, while a drop to zero receives a distinct final-light
  treatment.
- Added a finite stepped alternative for the effect when Reduce Motion is
  enabled. Decorative reaction layers remain noninteractive and hidden from
  accessibility.
- Added independent `Lock Position` and `Pass Pointer Input Through` controls to
  the menu bar and pixel context menu. Locking prevents accidental movement and
  preserves the pet's position between launches. Click-through passes pointer
  input to applications underneath, with the menu bar retained as the
  guaranteed recovery path.

## Refined in this release

- Made Smooth and Pixel progress bars and arcs represent quota only. Standard
  and Turbo now use identical progress geometry without directional chevrons,
  progress bolts, endpoint ticks, or endpoint glow.
- Moved Standard/Turbo into a separate localized badge. An eligible Turbo badge
  performs two bounded glow pulses when the tooltip appears, then becomes idle.
- Preserved the compact Smooth layout in Russian by placing its mode badge below
  the full `Доступно` heading without changing the approved panel size.
- Unified quota-transition classification across local history and consumption
  so resets, reconnects, corrections, long gaps, and identity changes do not
  invent consumption activity.
- Scaled absorbable models with the selected pet size: 48 × 48 pt for S,
  64 × 64 pt for M, and 80 × 80 pt for L.
- Rebuilt all 31 absorbable sprites so their complete pixel silhouettes and dark
  outer contours remain readable at S, M, and L without contact-sheet artifacts.

## Privacy and compatibility

- Reactions use the app's existing accepted quota snapshots. They add no quota
  reads, polling loop, process, dependency, backend, analytics, notification,
  or persisted reaction history.
- Existing pet size, tooltip style, visibility, quota-dynamics preference, local
  history, and launch-at-login state are preserved when updating. Position lock
  and click-through are stored independently and default to off.
- The preview remains arm64-only and requires macOS 14 or newer plus a locally
  installed and authenticated Codex CLI.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.7.0-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Saved settings and local quota history are retained.

## Known preview limitation

- On the current SwiftUI menu implementation, macOS exposes the localized
  menu-bar toggle title and check state to accessibility but omits its
  supplemental help. The custom pixel toggle exposes state and help but not a
  separate accessibility name. The labelled menu-bar control remains available
  to disable click-through.
