Fixes Codex CLI discovery for standalone installations, including `~/.local/bin/codex`.

Black Hole now also checks absolute directories in its inherited `PATH`. Existing
Codex.app and Homebrew installations keep their discovery priority. Missing or
non-executable files, directories, and broken symlinks are skipped; executable
symlinks are supported.

Version **0.12.1 (build 29)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** in the native menu bar.
Compatibility remains Apple silicon, macOS 14 or newer, with ad-hoc signing.
