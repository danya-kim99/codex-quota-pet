Quota-reaction rollback for Apple silicon Macs running macOS 14 or newer.

## Changed in this release

- Removed the automatic visual reaction to observed quota consumption because
  its procedural SwiftUI/Canvas presentation did not meet the app's visual
  quality bar.
- Restored the pet to its existing quota sprite, Standard/Turbo animation, and
  manual absorption behavior without an automatic consumption overlay or
  reaction-specific rendering cadence.
- Kept the shared conservative quota-transition classifier for local history
  and future consumption/reset work. A later consumption reaction will require
  a separately approved authored-frame design.

## Unchanged behavior

- Quota reads, refresh timing, reconnect handling, local history, Smooth/Pixel
  tooltips, S/M/L sizes, position lock, pointer click-through, fullscreen
  hiding, launch at login, and manual absorption remain available.
- The rollback adds no migration, preference, process, dependency, network
  request, analytics, notification, or persisted reaction data.

## Install or update

1. Download and unzip `Black-Hole-Codex-Quota-Indicator-v0.7.1-macos-arm64.zip`.
2. Quit the currently running app if updating.
3. Move `Black Hole Codex Quota Indicator.app` to `/Applications`, replacing
   the previous copy when prompted.
4. Open the app. Existing settings and local quota history are retained.

A locally installed and authenticated Codex CLI is required.
