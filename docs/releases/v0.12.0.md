# Black Hole v0.12.0

Adds personal confirmation for earned manual Codex reset credits.

Black Hole now reads `rateLimitResetCredits.availableCount` from the same local
Codex App Server quota response it already uses. A confirmed credit replaces the
tooltip header in both Smooth and Pixel styles; counts through 99 remain exact,
while larger visible counts use a compact `99+` label. VoiceOver always reads
the exact account count.

When Codex Resets announces a banked reset, the tooltip now distinguishes a
confirmed zero from unknown personal availability. The count stays memory-only,
adds no request or persistence, and clears when the App Server connection is no
longer current. Black Hole never applies or consumes a reset credit.

Version **0.12.0 (build 27)** uses the existing signed GitHub update channel.
Choose **Check for Updates… / Проверить обновления…** in the native menu bar.
Compatibility remains Apple silicon, macOS 14 or newer, with ad-hoc signing.
